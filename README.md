# 小熊猪银行

小熊猪银行（Kuma & Piggy Bank）是一款为小熊和小猪设计的情侣双币虚拟银行网页。小熊赚取并使用熊币，小猪赚取并使用猪币；两个人用它记录额外的关心、陪伴、惊喜与共同活动，并以 2000 年代日系个人主页、Webcore 和电子手账的方式呈现。

当前版本完成的是 `PROJECT_SPEC.md` 中的“阶段一：基础视觉原型”。固定价值关系为 1 熊币 = 5 猪币，两种币不提供充值、提现或自由兑换。页面中的余额、流水、奖励、目标、成就和统计均为演示数据。

在线演示通过 GitHub Pages 的 `gh-pages` 分支发布；`main` 分支保留完整源代码。

## 技术栈

- React
- Vite
- TypeScript
- React Router
- 普通 CSS

项目未使用大型 UI 组件库。小熊、小猪、熊币、猪币和邮票均为项目内原创 SVG 占位素材。

## 安装与运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

启动后，根据终端给出的本地地址在浏览器中访问。根地址固定显示银行门面：

```text
http://localhost:5173/little-bear-pig-bank/#/
```

## 构建与检查

```bash
npm run lint
npm run build
```

如需本地预览构建结果：

```bash
npm run preview
```

## 当前已完成

- 独立银行门面欢迎页，以及五个 React Router 主要页面：银行首页、赚币记录、奖励商店、流水账本、我们的小屋
- 根路由固定为银行门面，点击进入后前往 `/bank`；内部路由刷新时保留当前页面
- 桌面端居中的复古两栏布局
- 手机端单栏布局与固定五项底部导航
- 银行横幅、桌面导航、账户侧栏、汇率卡、公告、身份视觉切换
- 小熊熊币专属账户、小猪猪币专属账户、周数据、最近流水、待处理事项、共同目标和快捷入口
- 赚币记录视觉表单与演示成功提示
- 15 个按购买身份和专属币种定价的演示奖励，分为日常小券、用心奖励、礼物与旅行
- 日常奖励直接演示兑换；礼物和旅行采用预算、频率、延期及确认保护说明
- 流水类型前端演示筛选，以及移动端可滚动表格
- 纪念卡片、银行成就、月度报告和银行守则
- 统一 CSS 变量、轻微动画与 `prefers-reduced-motion` 支持
- 原创小熊、小猪、双币和邮票 SVG 占位素材

## 暂为演示数据或视觉交互

- 账户余额和折算总值
- 身份切换（刷新后不会保存）
- 表单提交（不会创建流水或改变余额）
- 奖励兑换（不会扣币或创建订单）
- 首页待处理事项及演示批准/退回按钮（刷新后不会保存）
- 流水数据和筛选结果
- 共同目标、纪念、成就和月度统计
- 搜索框与照片上传占位

本阶段刻意未接入 LocalStorage、真实登录、数据库、Supabase、云端同步、图片上传和支付功能。这些内容应严格按照 `PROJECT_SPEC.md` 的后续阶段逐步实现。
