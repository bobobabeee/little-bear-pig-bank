# 小熊猪银行

小熊猪银行（Kuma & Piggy Bank）是一款为“小熊”和“小猪”设计的情侣双币虚拟银行网页。它用熊币和猪币记录额外的关心、陪伴、惊喜与共同活动，并以 2000 年代日系个人主页、Webcore 和电子手账的方式呈现。

当前版本完成的是 `PROJECT_SPEC.md` 中的“阶段一：基础视觉原型”。页面中的余额、流水、奖励、目标、成就和统计均为演示数据，不涉及真实货币或金融服务。

在线演示通过 GitHub Pages 的 `gh-pages` 分支发布；`main` 分支保留完整源代码。

## 技术栈

- React
- Vite
- TypeScript
- React Router
- 普通 CSS

项目未使用大型 UI 组件库。小熊、小猪、熊币、猪币和邮票均为项目内原创 SVG 占位素材。

## 安装与运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

启动后，根据终端给出的本地地址在浏览器中访问。

## 构建与检查

```bash
npm run lint
npm run build
```

如需本地预览构建结果：

```bash
npm run preview
```

## 当前已完成

- 五个 React Router 页面：银行首页、赚币记录、奖励商店、流水账本、我们的小屋
- 桌面端居中的复古两栏布局
- 手机端单栏布局与固定五项底部导航
- 银行横幅、桌面导航、账户侧栏、汇率卡、公告、身份视觉切换
- 双人账户卡、周数据、最近流水、待确认事项、共同目标和快捷入口
- 赚币记录视觉表单与演示成功提示
- 12 个演示奖励、分类筛选与演示兑换弹窗
- 流水类型前端演示筛选，以及移动端可滚动表格
- 纪念卡片、银行成就、月度报告和银行守则
- 统一 CSS 变量、轻微动画与 `prefers-reduced-motion` 支持
- 原创小熊、小猪、双币和邮票 SVG 占位素材

## 暂为演示数据或视觉交互

- 账户余额和折算总值
- 身份切换（刷新后不会保存）
- 表单提交（不会创建流水或改变余额）
- 奖励兑换（不会扣币或创建订单）
- 待确认事项
- 流水数据和筛选结果
- 共同目标、纪念、成就和月度统计
- 搜索框与照片上传占位

本阶段刻意未接入 LocalStorage、真实登录、数据库、Supabase、云端同步、图片上传和支付功能。这些内容应严格按照 `PROJECT_SPEC.md` 的后续阶段逐步实现。
